# Universal Persistent Memory Substrate (UPMS)

UPMS is a model-independent memory service for continuing project work by people and agents. It preserves observations, keeps revisable assessments of them, and supplies what an integrated runtime needs to enforce permitted uses of memory.

## Status

UPMS is in architecture design. There is no implementation yet, and no architecture manual is accepted-current. The latest manual is a review candidate awaiting independent review before Gate 0 entry. See [`workplans/README.md`](workplans/README.md) for the documents and their lineage.

## Method

Development follows the Scientific Software Development Protocol (SSDP) 7.2.1. Agents and contributors should start with [`AGENTS.md`](AGENTS.md).
